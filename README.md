# 📝 Posting Page - Criador de Posts com API

![Posting Page Screenshot](https://via.placeholder.com/800x400/4361ee/ffffff?text=Posting+Page+Criador+de+Posts)

Uma aplicação web que simula a criação de posts (como Facebook/LinkedIn) com integração a uma API real. Este projeto demonstra o consumo de APIs REST usando JavaScript puro.

## ✨ Funcionalidades

- ✅ **Formulário de criação de posts** com título e conteúdo
- ✅ **Contador de caracteres** em tempo real
- ✅ **Integração com API externa** (JSONPlaceholder)
- ✅ **Renderização dinâmica** dos posts criados
- ✅ **Feedback visual** durante o envio
- ✅ **Design responsivo** e moderno
- ✅ **Animações e transições suaves**
- ✅ **Simulação de interações** (curtir, comentar, compartilhar)

## 🚀 Demonstração

**URL da API:** `https://jsonplaceholder.typicode.com/posts`

**Método:** POST

**Dados enviados:**
```json
{
  "title": "Seu título aqui",
  "body": "Seu conteúdo aqui",
  "userId": 1
}
